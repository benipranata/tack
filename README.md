# tack

**Dependency wiring in plain Go, generated from one small config file.**

You already write the functions that create your database, your logger, your cache.
tack finds them, matches them to the methods of an interface, and writes the constructor
that ties everything together. The result is ordinary Go you can read top to bottom.

- **One config file, one command.** Describe the interface, run `tack`, commit the result.
- **Plain output.** A constructor, a struct, and accessor methods. No reflection, no runtime magic.
- **Cleanup built in.** Every resource you open is closed in reverse order, including when a later step fails.
- **Clear errors.** A missing or ambiguous provider names the exact method and type, and every problem in your config is reported at once with its field path.
- **Deterministic.** Same config and source, same output. Review it like any other code.

## Install

```sh
go install github.com/benipranata/tack/cmd/tack@latest
```

## Quickstart

**1. Declare what you need** as an interface. Each method names a dependency by its return type.

```go
// internal/app/service.go
package app

type Service interface {
	DB() *sql.DB
	Logger() *slog.Logger
}
```

**2. Write providers** you probably already have. Every provider has the same signature:

```go
func Provide…(ctx context.Context) (T, func(), error)
```

| Return value | Meaning |
| ------------ | ------- |
| `T` | The type one interface method returns, such as `*sql.DB` for `DB()`. tack matches it exactly. |
| `func()` | The cleanup, called when the service is closed. Return `nil` if there is nothing to close. |
| `error` | Return it to stop wiring. Everything created so far is cleaned up first. |

For example:

```go
// internal/providers/providers.go
package providers

func ProvideDB(ctx context.Context) (*sql.DB, func(), error) {
	db, err := sql.Open("pgx", os.Getenv("DATABASE_URL"))
	if err != nil {
		return nil, nil, err
	}
	return db, func() { db.Close() }, nil
}

func ProvideLogger(ctx context.Context) (*slog.Logger, func(), error) {
	return slog.New(slog.NewJSONHandler(os.Stdout, nil)), nil, nil
}
```

**3. Point tack at them** in `tack.yaml`:

```yaml
prefix: New
providers:
  - internal/providers
targets:
  - package: internal/app
    interface: Service
```

**4. Run it.**

```sh
tack
```

tack writes `internal/app/service_gen.go`:

```go
// Code generated by tack. DO NOT EDIT.

package app

func NewService(ctx context.Context) (Service, func(), error) {
	var cleanups []func()
	cleanup := func() {
		for i := len(cleanups) - 1; i >= 0; i-- {
			cleanups[i]()
		}
	}

	db, dbCleanup, err := providers.ProvideDB(ctx)
	if err != nil {
		cleanup()
		return nil, nil, fmt.Errorf("ProvideDB: %w", err)
	}
	if dbCleanup != nil {
		cleanups = append(cleanups, dbCleanup)
	}

	logger, loggerCleanup, err := providers.ProvideLogger(ctx)
	if err != nil {
		cleanup()
		return nil, nil, fmt.Errorf("ProvideLogger: %w", err)
	}
	if loggerCleanup != nil {
		cleanups = append(cleanups, loggerCleanup)
	}

	return &service{db: db, logger: logger}, cleanup, nil
}

type service struct {
	db     *sql.DB
	logger *slog.Logger
}

func (s *service) DB() *sql.DB          { return s.db }
func (s *service) Logger() *slog.Logger { return s.logger }
```

**5. Use it.**

```go
svc, closeFn, err := app.NewService(ctx)
if err != nil {
	log.Fatal(err)
}
defer closeFn()

rows, err := svc.DB().QueryContext(ctx, "select 1")
svc.Logger().Info("ready")
```

Add a method to `Service`, add a provider, run `tack` again. That is the whole workflow.

## How providers are found

tack matches by **type**, not by name. For every method on your interface, it looks for a
provider returning exactly that type, searching in this order and using the first layer that has one:

1. the output's own `provider` package (if set)
2. the global `providers` packages
3. the output package

If nothing matches, or two providers in the same layer return the same type, tack stops and tells you
which method and which type.

## Several implementations of one interface

Give a target more than one output. Each gets its own name, package, file, and, if you want,
its own `provider`.

```yaml
prefix: New
providers:
  - internal/providers          # shared by every output: logger, config, ...
targets:
  - package: internal/state
    interface: State
    output:
      - name: NewProdState
        package: internal/state/prod
        provider: internal/providers/prod
      - name: NewStagingState
        package: internal/state/staging
        provider: internal/providers/staging
```

`NewProdState` takes what it needs from `internal/providers/prod` first and falls back to the shared
providers for everything else. `NewStagingState` does the same with `internal/providers/staging`.
The same works for a single output: add `provider` to override a few dependencies and keep the rest shared.

```yaml
targets:
  - package: internal/cache
    interface: Cache
    output:
      - provider: internal/providers/redis
```

## Testing

Turn on `test` and tack writes a test double next to each constructor, so a fake is a one-line swap.

```yaml
prefix: New
test: true
providers:
  - internal/providers
targets:
  - package: internal/app
    interface: Service
```

tack writes `internal/app/service_test_gen.go` with a fields struct and a constructor.
Every method of the interface becomes a field:

```go
svc := app.NewServiceTest(t, app.NewServiceTestFields{
	DB:     fakeDB,
	Logger: slog.Default(),
})
```

Forget a dependency and the test fails right away, naming the missing field.

`test` is off by default. Set it once at the top to cover every output, or on a single output to
override the global setting either way:

```yaml
test: true
targets:
  - package: internal/state
    interface: State
    output:
      - name: NewProdState
      - name: NewStagingState
        test: false       # no test double for this one
```

Switch `test` off again and tack removes the generated test file for you.

## Config reference

```yaml
prefix: New                   # optional; the generated function is prefix + interface (NewService)
test: false                   # optional; also generate test doubles, default false
providers:                    # optional; packages searched for providers
  - internal/providers
targets:                      # at least one
  - package: internal/app     # package that holds the interface
    interface: Service        # interface name
    output:                   # optional; defaults to one output
      - name: NewService      # optional; function name
        package: internal/app # optional; defaults to the target's package
        filename: service_gen.go  # optional; defaults to <lowercase interface>_gen.go
        provider: internal/other  # optional; searched before the global providers
        test: true            # optional; overrides the global test setting
```

All package paths are relative to your module root. `./internal/app/` and `internal/app` mean the same thing.

## Running tack

```sh
tack                       # generate for every target in tack.yaml
tack -config path/to/tack.yaml
```

Run `tack` from any directory inside your module. It walks up to find `tack.yaml`.
